# Glue or Wedge? Forces Lab

An interactive AP Human Geography lab (Topic 3.3) on centripetal and centrifugal forces. Student pairs work through six country cases (Belgium, Switzerland, Quebec, Northern Ireland, Sri Lanka, Indonesia) in three matchups. Each case has four steps: read the story, review the culture layer map, tag four street-scene clues, and give a glue-to-wedge verdict with evidence.

- **Lab:** open `index.html` (served by GitHub Pages)
- **Student worksheet:** `docs/Glue_or_Wedge_Worksheet.pdf`
- **Answer key:** `docs/Glue_or_Wedge_Answer_Key.pdf`

The lab is one HTML file with images in `img/`. Student work saves in each browser, so a refresh does not lose progress. The class board (link on the start screen) is a teacher tally screen for the share-out.
